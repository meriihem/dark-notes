Настройка Firebase

В Firebase Console зарегистрируй Web-приложение (значок ), затем скопируй объект firebaseConfig из раздела SDK setup. Вставь его сюда. Это одноразовая настройка.

Не отправляй сюда пароли или закрытые ключи. Firebase web config содержит публичные идентификаторы приложения; безопасность обеспечивают Authentication и Firestore Rules.
